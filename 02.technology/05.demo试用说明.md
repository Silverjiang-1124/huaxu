# 画序 Android Demo 试用说明

界面采用 React + Vite + Lucide 组件，参考《画序_安卓端交互Demo.html》实现首页、订单、排期和我的四个页面。Android WebView 载入打包在应用中的前端文件；Android 层提供选图、ML Kit 本机 OCR、SQLite 订单和本地设置，不连接服务器。已有订单数据库会保留。

- 首页可选取截图识别或手动记单；其他应用可分享单张图片进入画序。
- 微信资料页尝试提取昵称、微信号和昵称上方的备注月日，年份使用手机当前年份；识别结果必须核对，微信号可能识错。原图和识别原文不会保存到订单。
- 单据类型来自调研：只画头发、头发＋修图、修图（身材 / 滤镜）、其他；类型仍需客户试用确认。
- 新订单默认每张 30 分钟，可在“我的 → 默认每张工时”修改；订单中可单独调整每张分钟数，总工时按数量相乘。修改默认值仅影响新订单，旧订单维持原值。升级前的旧数据补为“未选择”、每张 30 分钟，属于估算并可编辑。
- 日期与提醒时间使用 React 日历和时间选择组件；提醒通过 Android 应用通知发送，选图仍调用系统媒体选择器。
- “我的”页看板可按全部时间、本月或自定义区间统计已完成单数和已完成订单约定金额；金额不代表实际到账。排期按交付日汇总预计工时，不代表这些工作实际安排在当天。
- 自动读取微信、自动回复、备份及云同步未接入。订单仅存在本机，卸载或清除应用数据将丢失。

## 构建与调试

首次执行 `cd web`、`npm ci` 安装前端依赖。回到项目根目录执行 `gradlew.bat assembleDebug`；Gradle 会在 Android 构建前自动运行前端构建。用 VS Code 的“Android: 安装并启动 Demo”任务安装，或安装 `app/build/outputs/apk/debug/app-debug.apk`。

前端代码位于 `web/src/`；`npm run dev` 可在浏览器查看页面，浏览器不具备 Android 选图、OCR 和 SQLite 桥接能力，完整流程需要模拟器或真机。`app/src/main/assets/web/` 是自动生成的构建产物，请不要手动修改。
