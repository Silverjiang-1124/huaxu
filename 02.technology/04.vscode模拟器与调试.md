# VS Code Android 模拟器使用

2026-10-31：已安装 VS Code 扩展 EmbeDroid 1.0.2 和 Android for VS Code 1.4.0；Android Emulator 37.2.13、Android 15 x86_64 虚拟设备 `ArtistDemo_API35` 已创建。系统镜像及模拟器包已与 Google 官方索引校验，Windows Hypervisor Platform 加速可用。

## 查看启动页

1. 用 VS Code 打开项目文件夹 `D:\CODE\01.artist-commission-app`。如扩展刚安装，请执行“开发人员: 重新加载窗口”。
2. 点击左侧 EmbeDroid 的 Android 图标；在 Running Devices 中选择 `ArtistDemo_API35` / `emulator-5554`，即可打开内嵌画面。如果当前没有运行设备，则在 Available AVDs 里启动 `ArtistDemo_API35`。
3. 模拟器首次启动可能需要等待；当前启动页 APK 已安装。修改代码后，通过“终端 → 运行任务 → Android: 安装并启动 Demo”重新编译、安装和启动。此流程不属于 Compose 热重载。
4. 当前安装及启动过程已通过 ADB 验证，截图确认启动页正常；EmbeDroid 画面嵌入 VS Code 的实际交互尚需在用户 VS Code 界面中确认。

## 断点调试

`.vscode/launch.json` 提供“Android: 构建并调试 Demo”，选择后可按 F5；其构建任务先执行 Gradle，再由 Android for VS Code 扩展部署调试版本。该扩展为预览版，Kotlin/Compose 断点、变量查看及 F5 全链路尚未在 VS Code 图形界面验证。如断点未命中，请记录扩展错误；Android Studio 是原生 Android 调试的备选方案。

模拟器使用的是项目测试数据。`.vscode/settings.json` 和运行任务的 ADB 路径指向本机 `D:\CODE\android-sdk`；换电脑后需调整。首次模拟器设备通过手工 AVD 配置创建，因为现有命令行工具未能识别手动安装的模拟器包；已验证模拟器启动。设备配置位于用户目录 `.android/avd`，不属于 Git 项目。
